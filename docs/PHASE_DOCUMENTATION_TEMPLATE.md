# Phase documentation template

Copy this outline only when a new phase is authorized and implemented. Replace each
placeholder with evidence; explicitly mark unexecuted checks and unresolved assumptions.

## 01_beginner_guide.md

Explain the problem, prerequisites, new terminology with analogies, exact setup and
commands, one worked success and failure, troubleshooting, and a quiz with answers.

## 02_technical_design.md

Define the formal problem, scope, assumptions, architecture/data flow/sequence diagrams,
component responsibilities, data models and wire rules, cryptographic/trust decisions,
threat model, resource bounds, failure states, and implications for the next phase.

## 03_code_walkthrough.md

For each relevant module/function: path, purpose, inputs, outputs, algorithm, important
decisions, failure modes, and test references. Include short code snippets and trace one
success and one rejection. Explain changes relative to the prior phase accurately.

## 04_testing_and_results.md

Record date, platform, Python/dependency versions, exact commands, expected and actual
outcomes, machine-readable logs when helpful, regressions fixed, reproduction procedure,
and unexecuted tests. Keep functional checks distinct from controlled benchmarks.

## 05_ppt_content.md

For each slide: title, concise bullets, suggested figure/screenshot, speaker notes,
likely viva question, and supported answer. Include limitations and next evidence gate.

## 06_research_findings.md

Separate proposal claims, external evidence, experiment findings, inferences, unresolved
questions, and required cooperation. Include decision matrices where helpful. State
whether the phase's core research question was answered and under which assumptions.

## 07_sources_and_assumptions.md

List exact URLs, access dates, document/version/section, official versus third-party
status, and retrieval limitations. For every important claim record source, evidence,
confidence, whether tested, and remaining uncertainty. Label project design decisions
separately from issuer facts.
